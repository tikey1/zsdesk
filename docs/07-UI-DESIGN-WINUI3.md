# tabbed_files 全新界面设计方案 v2
## Windows 10 / WinUI 3 风格 · 美观、易用、符合既有习惯

日期：2026-11-13
适用工程：`tabbed-files/`（Rust + Win32 + Core UI 1.9.0.346 / Fluent 2）
性质：**界面设计方案**，不改运行时架构，不引入任何浏览器 / WebView / 新依赖。

---

## 0. 目标与不可逾越的边界

**三个目标**：一眼就会用（继承 Windows 文件资源管理器肌肉记忆）、看起来是当代 Windows 原生应用（Fluent / WinUI 3 视觉语言）、在既有架构里能落地。

**硬约束（沿用项目 §0 / D-15 / R1~R12）**：

| 约束 | 对设计的含义 |
|---|---|
| 单进程、无 WebView / V8 / Node、发布包 ≤10MB、仅 x64 | 不采用 Web 技术做 UI，不引入图标字体大包，不引入新 crate |
| `.uix` 只声明布局 / 样式 / 主题 token，**无事件、无业务脚本** | 设计方案里的所有交互仍由 Rust 经 Core UI 纯 C API 挂载 |
| 文件列表由 `ui_custom_on_draw` 从 `EntryStore` 自绘 | 列表视觉规范是「绘制规范」，不是 XAML 控件树 |
| **首版只读浏览** | 命令栏不出现新建 / 删除 / 重命名 / 剪贴板写操作；只提供导航、查看、排序、筛选、预览、刷新 |
| K-01～K-18 ABI 未真机核对 | 方案不新增未核对的 C API 调用；降级路径（`PureCApi` 自检提示）要有一张明确的界面 |
| 性能预算 / 缓存上限 / 降级不空白 | 每个状态都有可读文案和恢复动作 |

> 参考对象是 **WinUI 3 的组件语义与视觉规范**，不是把 XAML 控件搬进来。

## 1. 信息架构

```
主窗口
├─ 标题栏（自定义）：应用标识 · 全局搜索 · 窗口按钮
├─ 标签栏 TabView：多标签 + 「+」 + 标签菜单
├─ 命令栏 CommandBar：导航 / 查看 / 排序 / 预览 / 刷新（只读）
├─ 地址与搜索条：面包屑 + 筛选搜索框
├─ 工作区
│   ├─ 左侧导航窗格 NavigationView：快速访问 / 此电脑 / 网络 / 收藏
│   ├─ 中间文件列表 ItemsView：虚拟列表（自绘）
│   └─ 右侧预览窗格：缩略图 + 元数据 + 通道状态
├─ 信息条 InfoBar：降级 / 错误 / 提示（按需出现）
└─ 状态栏：项目数 / 选中 / 视图 / 缩放 / 通道 / 缓存
```

**状态归属**：每个标签独立持有 路径、选中项、滚动位置、排序、视图模式、搜索条件、预览开关；切换标签不重新枚举（NFR-05 ≤50 ms）。全局共享的只有主题、窗口尺寸、导航窗格展开状态。

## 2. 布局规范（基准 1200×800 @100% DPI）

| 区域 | 高度 / 宽度 | 说明 |
|---|---|---|
| 标题栏 | 32 px | 自定义标题栏，与标签栏同色，避免两层割裂 |
| 标签栏 | 36 px | 标签高 32，选中标签底部 2 px accent 指示条 |
| 命令栏 | 40 px | 图标 20 px、按钮 32×32、组间 8 px 分隔 |
| 地址与搜索条 | 36 px | 面包屑自适应，搜索框固定 220 px |
| 左侧导航窗格 | 220 px（可折叠至 48） | WinUI3 NavigationView 紧凑模式 |
| 右侧预览窗格 | 320 px（可折叠至 0） | 图片优先，文本 / 属性回退 |
| 状态栏 | 28 px | 左：计数；右：视图切换 + 缩放 |
| 分隔线 | 1 px | `--divider` |

**8 px 栅格**：控件内间距 4 / 8 / 12，区域间 16，窗口外边距 12。
**响应式断点**：

| 窗口宽度 | 行为 |
|---|---|
| ≥1100 | 导航窗格 + 列表 + 预览三栏全开 |
| 900–1100 | 预览窗格默认折叠，可由 Alt+P 呼出 |
| 700–900 | 导航窗格收成图标条（48 px） |
| <700 | 导航窗格变汉堡抽屉，命令栏折叠为「…」溢出菜单 |

## 4. 视觉语言

**字体**：Segoe UI Variable（Win11）/ Segoe UI（Win10），正文 13 px、次要 12 px、标题 14 px；字重仅 400 / 500。中文回退 Microsoft YaHei UI。

**颜色 token**（扩充现有 `assets/themes.json`，新增 hover / pressed / focus / 语义色 / 圆角 / 间距）：

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--bg` | `#F3F3F3` | `#202020` | 窗口底 |
| `--content-bg` | `#FFFFFF` | `#2B2B2B` | 列表、输入框 |
| `--toolbar-bg` | `#F7F7F7` | `#2B2B2B` | 标签 / 命令 / 状态栏 |
| `--sidebar-bg` | `#FBFBFB` | `#252525` | 导航 / 预览 |
| `--text` / `--text-secondary` | `#1B1B1B` / `#616161` | `#F5F5F5` / `#B3B3B3` | 前景 |
| `--divider` | `#E0E0E0` | `#3D3D3D` | 1 px 分隔 |
| `--accent` | 跟随系统 `AccentColor` | 同 | 选中指示、焦点、链接 |
| `--hover` / `--pressed` | `#00000008` / `#00000012` | `#FFFFFF0F` / `#FFFFFF18` | 交互态 |
| `--selection-bg` | `#E6F1FB` | `#1B3A5C` | 选中行 |
| `--info` / `--warning` / `--danger` | 蓝 / 琥珀 / 红 | 同系 | InfoBar 语义 |

**形状与层次**：控件圆角 4 px、浮层 / 卡片 8 px；边框 1 px `--divider`；焦点环 2 px `--accent` + 2 px 偏移。材质：Win11 22H2+ 可选 Mica（标题栏区域），Win10 一律纯色回退；**不依赖 Acrylic / 模糊**（性能与兼容性）。

**图标**：Segoe Fluent Icons 线性风格，16 / 20 px，单色跟随 `--text`，选中态跟随 `--accent`；以路径数据内嵌，不引入字体文件。

**动效**：120–200 ms 淡入 / 位移，仅用于标签切换、浮层出现、预览切换；尊重系统「减少动画」设置，禁用时立即切换。

## 5. 符合用户习惯的交互映射

| 习惯 | 快捷键 / 手势 | 设计响应 |
|---|---|---|
| 新建 / 关闭标签 | `Ctrl+T` / `Ctrl+W`，中键点标签，双击标签关闭 | 标签栏 |
| 后退 / 前进 / 上级 | `Alt+←` / `Alt+→` / `Alt+↑`，鼠标侧键 | 命令栏导航组 |
| 地址 / 搜索 | `Ctrl+L` / `Ctrl+F` | 面包屑切输入 / 筛选框聚焦 |
| 列表选择 | `Ctrl+A`、方向键、Shift 连选、Ctrl 多选 | 虚拟列表 |
| 预览 | `空格` 快速预览、`Alt+P` 预览窗格 | 右侧窗格 / 轻量浮层 |
| 视图 | `Ctrl+Shift+1～8`、`Ctrl+滚轮` 缩放图标 | 状态栏视图切换 + 缩放 |
| 刷新 | `F5` | 命令栏 |
| 全屏 / 新窗口 | `F11` / `Ctrl+N` | 标题栏菜单 |
| 右键 | 上下文菜单 | 自绘 MenuFlyout |

**首版只读的明确处理**：不出现「新建 / 删除 / 重命名 / 剪切 / 粘贴」按钮，`F2` / `Delete` 不绑定动作；若用户触发，InfoBar 给出「当前为只读浏览版本」的可读说明，而不是静默无响应（对应 R7 降级不空白）。

**键盘可达**：Tab 顺序 标题栏 → 标签 → 命令栏 → 地址 → 搜索 → 导航 → 列表 → 预览 → 状态栏；所有可交互元素焦点可见；为每个控件提供 narrator 名称与状态。

## 6. 状态与反馈（每态有文案，不空白）

| 状态 | 界面表现 |
|---|---|
| 载入中 | 列表骨架行 + 状态栏「正在载入…」细进度 |
| 空目录 | 居中图标 + 「此文件夹为空」 |
| 搜索无结果 | 「没有找到匹配项」+ 清除筛选按钮 |
| 无选中 / 多选 | 预览窗格「选中单个文件以预览」/「已选中 N 项」 |
| 预览失败 | 缩略图位置显示扩展名图标 + 具体通道状态 |
| core-ui.dll 缺失 | InfoBar（danger）：说明按 exe 同目录绝对路径加载、给出补齐方式 |
| ABI 未核对 | InfoBar（info）：「已进入 PureCApi 自检降级模式」+ 自检结果 |
| 监听失败 | 状态栏「目录监听不可用，按 F5 手动刷新」 |

## 7. 深浅色、DPI 与可访问性

- 默认跟随系统主题，设置里可手动覆盖（浅 / 深 / 跟随系统）；切换不重启、不重建窗口。
- 高对比度模式：忽略 `--accent` 与材质，全部改用系统色，浮层用系统菜单样式。
- DPI：100 / 125 / 150 / 200% 逐档核对，图标走矢量路径，布局用逻辑像素 + 系统缩放，不出现 1 px 线条消失或文字截断。
- 文本缩放：跟随系统字体缩放，最小 11 px，列表行高随字体增长。

## 9. 分阶段落地

| 阶段 | 内容 | 风险 |
|---|---|---|
| **P0** | `main.uix` 骨架 + token 扩充 + 标签 / 地址 / 列表 / 状态栏绘制规范 + 全状态文案 | 低：只动静态布局与自绘，不新增 C API |
| **P1** | 面包屑、命令栏、筛选搜索、预览窗格折叠、深浅色跟随 | 中：需与 `Toolbar`/`PreviewPane` 状态同步 |
| **P2** | 动效、TeachingTip、高对比度、DPI 精调、写操作（若产品放开只读） | 高：写操作会触碰大量业务红线 |

> 建议先做 P0，且**必须先完成 K-01～K-18 ABI 真机核对**，否则 Core UI 挂载点是否可用仍未知，界面重绘无法验证。
